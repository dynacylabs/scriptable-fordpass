Set up the FordPass widget in a couple minutes

An unofficial Ford/Lincoln vehicle widget for Scriptable (iOS). One file, no account of ours, no server — it talks straight to Ford's own app API from your phone.

Install

Four steps, all on your iPhone/iPad. See the README for the full write-up.

1

Install Scriptable

Free app from the App Store. This widget needs nothing else installed.

Download Scriptable ↗
2

Copy the script

Grabs the latest FordPass.js straight from GitHub onto your clipboard. Nothing else is sent anywhere.

3

Paste, rename & run

Opens Scriptable to a new, blank "Untitled Script". Paste (⌘V / long-press → Paste), then rename it — tap "Untitled Script" at the top and type FordPass (Scriptable can't name it for you automatically). Then tap ▶ to run it once.

Open Scriptable ↗
4

Sign in & add widget

Pick your region, sign in with your real Ford/Lincoln account when the window opens, choose your vehicle(s), then add a Scriptable widget to your home screen pointing at this script.

This is unofficial and unsupported by Ford — it can break without notice, and some owners report extra scrutiny on accounts using third-party API access. Consider a secondary FordPass login rather than your primary one. Full details in the README.

Build your widget config

Pick what shows on your widget, in what order, then paste the result into the widget's Parameter field (long-press the widget → Edit Widget → Parameter). You can also do all of this from the script's own in-app configurator (run the script → Configure widget) — this is the same tool, just easier to browse on a bigger screen.
